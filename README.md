# PostoHub Updates

Public release feed for immutable PostoHub Desktop and Mobile artifacts.

The binary files remain in GitHub Releases. The `desktop/` and `mobile/`
directories contain only lightweight release manifests, SHA-256 hashes and
links generated by the PostoHub CI workflows. GitHub Actions artifacts are not
used as a distribution channel.

- Desktop tags: `desktop-vX.Y.Z`;
- Mobile tags: `mobile-vX.Y.Z`.

Published tags and assets are immutable.
